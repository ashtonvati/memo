| ESP32 pin   | Goes to                                 |
| ----------- | --------------------------------------- |
| **3.3V**    | INMP441 VDD, SD reader 3V3, Display VCC |
| **GND**     | Everything - use a common ground rail   |
| **GPIO 13** | SD CS                                   |
| **GPIO 12** | SD MOSI                                 |
| **GPIO 11** | SD CLK                                  |
| **GPIO 10** | SD MISO                                 |
| **GPIO 2**  | INMP441 SCK (BCLK)                      |
| **GPIO 3**  | INMP441 WS (LRCLK)                      |
| **GPIO 1**  | INMP441 SD (DOUT)                       |
| **GPIO 6**  | Button 1                                |
